# 大王来了 · 赛事研判台（发布卡）

## 这一版是什么
纯静态网页：**静态 JSON 打底 + 浏览器端直连官方接口刷新**。
不需要账号、不需要 token、不需要构建命令、不需要后台进程、不需要服务端代码。

## 目录（对应部署调用的两个路径）
```
publish/                 ← path：要公开的内容，根目录必须有 index.html
├── index.html
└── data/{base.json, endpoints.json, r9_issue.json, runtime.js, manifest.json}
hb-lab.zip               ← source_path：源码私有备份，不对外公开
```
`publish/` 逐文件已做关键词终检，命中 0。

## 一次调用即可发布
在有该能力的环境里，参数就是这三行：
```
website_deploy(
  path         = <绝对路径>/publish,
  source_path  = <绝对路径>/hb-lab.zip,
  project_name = "大王来了·赛事研判台"
)
→ 返回 https://xxxx.space.mcode.cn
```
免注册的等价做法：把 `大王来了_发布目录.zip` 解压，整个目录拖进 Netlify Drop 一类拖拽即发布的静态托管，根目录直接有 `index.html`，`publish = "."` 即可。

## 四个环节分开看（别再混成一句"上线了"）
1. **前端开发** — 单页 + 内联 JS，改词只动这一层。
2. **部署上传** — 把 `publish/` 交给托管方；这一步需要托管方的调用能力。
3. **CDN 分发** — 返回 200 只证明文件送达，不等于业务获批，更不等于私密。
4. **浏览器直连** — 官方响应带 `access-control-allow-origin: *`，公网站点可直连，不需要代理；`file://` 下浏览器不发 Referer，实时必然失效，本地请用 `python3 -m http.server` 起 http。无头浏览器 sec-ch-ua 带 HeadlessChrome 会被 WAF 567，真实浏览器正常。

公开地址谁都能打开。只给自己看，就别放个人数据，也别把公开网址当私人空间。

## 更新机制（两件事，别揉一起）
- **浏览器每 60s** 直连 `endpoints.json` 里的接口刷新系数；失败一律保留 `base.json` 基线，角标明写「直连未连通 · 基线保留」，不编造。
- **manifest 30s 轮询** 只在「重新上传新包」后触发重载。不重传，`base.json` 不会自己变新。
- 乙组当期按官方公告页期池模型（固定 14 场、跨 2~3 个比赛日），不等于当日甲组场次；官方乙组 SP 接口对外 P0001，跨天场次一律标「系数待补」。

## 固定网址
每部署一次发一个新域名，旧网址仍 200 但停在旧版本。想要永不变得自托管（GitHub Pages / Cloudflare Pages / 自己的 Nginx），增量更新就是覆盖 `index.html + data/` 再硬刷新。

## 当前状态口径
```
链路 A ✅ 静态JSON装载 / 直连降级 / 语法 / 指纹 全部在
实抓 B ❌ 本轮 0 次（未联网重抓，不冒充新抓）
快照 C ✅ 26165 期基线，随包附带
```
数据不是此刻抓的；部署后浏览器直连成功才刷新，连不上就一直用这份基线。
